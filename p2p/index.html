Peer-to-peer test

Can these devices talk to each other directly, without the laptop relay? Open this page on two or more devices, give each the same room code and press Start. The first device becomes the room's host; the others link to it.

Try it on the network you will use: two headsets on the same Wi-Fi, and a phone on mobile data with a headset on Wi-Fi. Then enter VR on a headset for a minute: the link should keep running.

Events

    How it works: PeerJS 1.5.5 (MIT licence, vendored next to three.js) and its free public server, 0.peerjs.com, introduce the devices; Cloudflare's free STUN server, stun.cloudflare.com, tells each device its public address; after that the messages go straight from device to device. The introduction server, Cloudflare and the other devices see each device's IP address. Nothing else leaves the page, and nothing is stored.
