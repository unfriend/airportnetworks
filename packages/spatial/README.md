# Spatial interactome: Cell map (`#spatial`)

249 proteins in the compartments of a model cell. Proteins that move, signals that cross the cell, proteins in the wrong place.

One of the app's own stories, a story package since it moved here (docs/packages-migration.md). Made by the app's authors;
hand-written: `main.js` is its source (no build; edit it, then `node tools/packages/scan.mjs`). Its data and the permission
to show it: `docs/data-and-permissions.md`.
